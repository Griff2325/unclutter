Privacy and provider permission

Unclutter for Safari · Bring your own API key

Effective October 26, 2026. This policy describes this independent, client-only Safari fork. There is no project-operated backend, advertising analytics, or telemetry in the extension.

Data on your device

The extension stores your API key, provider selection, consent, paused website origins, and cached template rules in Safari extension storage on this device. It does not sync that storage. The key is not separately encrypted by the extension and is not stored in Keychain. Protect access to your device and revoke exposed keys through your provider.

When data leaves the browser

No model request is made until you save a key and explicitly allow the selected provider to process snippets. In Manual mode, Analyze / Re-analyze sends a request. On page visit additionally authorizes requests for new eligible page templates in visible tabs. Each request can incur charges to your provider account. Saved templates are reused locally.

Requests contain the page kind and up to 60 element descriptions: tag, short structural signals and text, position, and match count. We skip main content containers and form controls, redact email-like and long numeric strings, and omit full page URLs, page titles, cookies and raw HTML from the model request. This does not guarantee anonymity: remaining snippets can contain names, private text or other personal information. Do not analyze sensitive pages.

Who receives requests

TypeSafe AI receives requests directly at api.typesafe.ai when selected. Vercel AI Gateway receives requests at ai-gateway.vercel.sh and routes Jev evaluation to TypeSafe when Gateway is selected. The selected service receives your API credential for authentication and normal connection metadata such as your IP address. The project developer does not receive these requests or your key.

Provider handling, retention, deletion, and billing are governed by your provider account and agreements. Review TypeSafe’s privacy policy, Vercel’s privacy policy and your service terms. We cannot promise provider-side zero retention or delete data already sent to them.

Permission, deletion and revocation

Uncheck provider permission in Connection to stop future requests and return to Manual mode. This cannot recall an in-flight request or delete provider records. Pause this website stops both analysis and cached cleanup on that exact origin. Safari’s per-website access controls can also revoke the extension’s access.

Remove saved key deletes the local API key without deleting cached rules. Forget this page type deletes that template’s local rules. To revoke the credential itself or request deletion of provider-side data, use the provider’s account controls. Cached rules and settings remain local until removed; uninstalling the containing app alone may not clear Safari website/extension data. Use Safari’s data-management controls to remove any remaining stored extension data.

Support and changes

GitHub issue reports are public and subject to GitHub’s privacy policy. Avoid keys, private URLs and personal screenshots. Report privacy concerns through the repository’s private security-report form. Material changes to destinations or sharing will require updated disclosure and permission before requests are allowed.
