Set up Safari cleanup

Unclutter for Safari · Bring your own API key

This beta hides page elements. It does not block ad network requests, reject cookies, or bypass paywalls.

  1. Enable the extension. Open Safari → Settings → Extensions and select Unclutter. On iPhone, open Settings → Apps → Safari → Extensions, or Safari’s Page Menu → Manage Extensions, and enable Unclutter. An iPhone development build must be installed through Xcode; an iPhone ZIP cannot be installed like a Mac app. Mac public downloads must be notarized; they should not require unsigned extensions.
  2. Allow a website. Open a normal HTTP or HTTPS website and use Safari’s extension toolbar controls to allow access to that website. Begin with one public site; avoid sensitive accounts and private pages.
  3. Add your own key. In the popup’s Connection section, choose TypeSafe AI or Vercel AI Gateway, paste the matching API key, and Save. Get a key from the TypeSafe console or Vercel AI Gateway. You pay that provider directly. Changing provider removes the previous key.
  4. Review permission and cost. Read what is sent and check the provider-permission box. Saving a key or changing permission returns to Manual mode without making a test request.
  5. Analyze once. Click Analyze page. It sends up to 60 descriptions to your provider and can incur charges. Saved rules apply on later matching pages without another model request. You can try the local sample demo without a key or network request.

Stay in control

Manual is the default. On page visit analyzes new page templates automatically after you opt in; charges can accumulate across sites. Use your provider’s spending controls. Pause this website stops both cleanup and analysis on that exact website origin. Pause / Resume affects the current page template; uncheck an individual rule to keep that element visible.

When something looks wrong

Pause cleanup first to restore the page. Refresh after installing an update. Safari’s Start Page, PDFs, browser settings, extension stores and file URLs are unsupported; open a normal website instead. A saved key is not a successful connection test: Analyze page verifies access and may be billed.

If ads remain after an update, cached rules may need Re-analyze once. Existing rules remain if the provider fails. Some iframe content, shadow DOM, changed selectors, or complex scroll locks may still be missed.

Updates and support

Replace the app in the same installed location and keep only one copy. A change from unsigned to certificate-signed builds may require one-time setup again. Use the project’s GitHub releases for future Mac beta updates. iPhone development updates come through Xcode; a future iPhone beta would use TestFlight. This project does not install updates automatically.

When reporting a bug, include the beta version, Safari and macOS/iOS versions, a public site if possible, what happened, and whether Pause restored it. Never post an API key, account page, private URL, or unredacted personal data.
