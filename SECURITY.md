# Security reporting

Do not post API keys, private browsing data, or an exploitable vulnerability in a public issue. GitHub private vulnerability reporting is enabled for this repository. Use [Report a vulnerability](https://github.com/Griff2325/unclutter/security/advisories/new) to contact the maintainer privately; a GitHub account is required. If that channel is unavailable, open a minimal issue requesting a private reporting channel without disclosure details.

The beta uses local Safari extension storage, not a project server or Keychain. Do not describe stored keys as encrypted by this extension. Model content is untrusted; only code-selected selectors and validated categories can affect the page. Changes must preserve sender checks, protected-content validation and paid-request consent/deduplication.

The privacy and credential boundary tests are not a complete independent security audit. Record unresolved limitations and provider handling in PRIVACY.md before public release.
